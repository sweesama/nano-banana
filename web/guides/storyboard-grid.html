Split a Storyboard Grid into Frames

You already have one image made of equal rectangular panels. This page cuts out the panels you select. It does not draw new frames, raise the resolution, or make the shots match.

The file stays in this tab. There is no upload, account, model call, or payment step. PNG and JPEG are decoded by the browser you are using. A color profile, JPEG compression, or a JPEG orientation tag can make those pixels differ from another program. Opaque pixels are copied from that decoding. A partly transparent pixel can move by one level, because the browser canvas rounds it while undoing premultiplied alpha. The crop is that decoded rectangle at the same size, not a reconstruction or a larger image.

Set the rows, columns, outer padding, and the gaps between panels. Padding is the same on every outer edge. The horizontal gap is only the space between columns, and the vertical gap is only the space between rows. If a cell would not land on a whole number of pixels, the page stops and names what is left over. It will not round down and take a strip of the next panel or the gap. Hand-drawn boards, perspective collages, and grids whose gaps change from panel to panel are outside this tool. It does not search for edges.

One file can be at most 8192 px on a side and 32 million pixels, and the grid can have at most 100 panels. Anything larger is refused before a crop is built.

Crop the grid

For example, a 1024×412 image with 2 rows, 3 columns, outer padding 20, and a gap of 12 on both axes divides into 320×180 panels. Use those numbers only when the file was built with that margin and gap. The boxes are numbered left to right, then the next row. shot_01.png stays panel 1 even when you leave other panels out.

Choose a PNG or JPEG. Nothing is uploaded.

What the files are

The preview is scaled to fit this page. The pixel sizes next to the panels are the downloaded sizes. One selected panel downloads as its PNG. Two or more download as storyboard-shots.zip, in row-major source order. Panels 2 and 5 are shot_02.png and shot_05.png, not a renumbered pair. Choosing another file, or Clear, drops the previous crop before anything new is decoded. A file that cannot be read does not leave the last download active.

These files are the cropped panels only. Cropping does not remove a caption inside a panel, sharpen it, or produce the video those stills might later condition. If you already have a rendered clip and need its opening and closing images, that is a separate tool: first and last frame video. This page does not open a video, and that page does not cut a grid.

FAQ

Does this page generate a video?

No. It only crops panels from a PNG or JPEG already on this device. It does not call a video model, and it does not make the panels consistent with each other.

Is the image uploaded?

No. The file is decoded in this browser tab, and the PNG or ZIP is built in this tab. This page has no upload request, account, or payment step.

What if the panel size would not be a whole number of pixels?

The page reports the leftover pixels, or a remaining width or height that is zero or negative, and it does not crop. It does not round a cell down, because that would include a strip of the gap or the next panel.

Are captions or numbers inside a panel removed?

No. The crop keeps the decoded pixels in that rectangle, including a caption, number, or border that sits inside the panel.

Does the download get sharper or larger?

No. Each PNG is that rectangle at the size the browser decoded. The page does not upscale, denoise, or redraw the panel.
