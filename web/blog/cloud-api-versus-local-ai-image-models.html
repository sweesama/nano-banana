AI image editing workflow: Cloud API versus Local AI Image Models

Learn when to use cloud APIs like Nano Banana versus local open-weight models, and how to fix common AI image API errors with practical steps.

Cloud API vs Local Open-Weight Models

Nano Banana provides a cloud‑based API powered by Google’s Gemini image models. As noted in the FAQ, the Pro model is closed‑source and cannot run totally offline, though a local Python client can call the cloud service FAQ. This means you rely on network latency and the free tier offered by Google’s Gemini API for experimentation FAQ. For users who need a fully offline workflow, the quickstart guide lists open‑weight alternatives such as Z‑Image, Qwen‑Image, and GLM‑Image that can be run on local hardware quickstart guide.

According to the quickstart overview, cloud‑only routes include Nano Banana 2, ChatGPT Image 2, and Seedream 4.5, while open models like HunyuanImage 3.0, Qwen‑Image 2.0, Z‑Image/Turbo, GLM‑Image, and HiDream‑O1‑Image are deployable locally with the appropriate GPU quickstart. The guide also notes that most open models need 16 GB–48 GB of VRAM, but a cloud GPU can be rented (e.g., an A100 for ≈ $0.40 per hour) to run them without owning hardware quickstart.

Fixing AI Image API Errors: Practical Steps

When you encounter errors such as authentication failures, quota exceeded, or proxy issues while using the Nano Banana cloud API, follow these steps to diagnose and resolve the problem:

  1. Verify that your API key is correctly set. The quickstart shows setting GOOGLE_API_KEY or GEMINI_API_KEY in your terminal quickstart.
  2. Check the Google AI Studio console for any billing alerts or quota limits; the FAQ notes that heavy commercial use may require a paid billing account FAQ.
  3. If you see a “proxy error” or connection timeout, ensure your network allows outbound HTTPS to generativelanguage.googleapis.com and that no corporate proxy is interfering. The troubleshooting installation guide offers tips for checking proxy settings troubleshooting guide.
  4. Test a minimal request using the Python snippet from the quickstart:
    pip install google-genai
from google import genai
client = genai.Client(api_key="YOUR_KEY")
response = client.models.edit_image(
    model="gemini-3.1-flash-image",
    prompt="Make the cat wear sunglasses",
    image=your_image)
    If this succeeds, the issue lies in your surrounding script or environment.
  5. Consider switching to an open‑weight model for offline work if cloud reliability is a concern. The quickstart provides installation commands for models such as Qwen‑Image 2.0 and Z‑Image/Turbo quickstart.
